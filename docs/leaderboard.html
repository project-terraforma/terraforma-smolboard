Parameters
Model Name ▾ SMOLBoard Score ▾ Case Acc. ▾ Match Acc. ▾ Easy Neg. Acc. ▾ Hard Neg. Acc. ▾ F1 ▾ Precision ▾ Recall ▾ Benchmark Date ▾

SMOLBoard Score = 100 × (0.50 × match accuracy + 0.15 × easy-negative accuracy + 0.35 × hard-negative accuracy). Matches and non-matches each count for half, so a model that always answers MATCH, always answers NO_MATCH, or guesses scores 50. Hard negatives weigh more than easy ones because that is where models differ.
